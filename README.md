# D-Kitchen Restaurant Website

A modern and responsive restaurant website built with HTML, CSS, Bootstrap, and JavaScript.

---

## Features

- Responsive Navigation
- Hero Carousel
- About Section
- Featured Menu
- Shopping Cart
- Search Food
- Favorites (Wishlist)
- Reservation Form
- Contact Form
- Google Maps
- Dark Mode
- Newsletter
- Responsive Design

---

## Technologies Used

- HTML5
- CSS3
- Bootstrap 5
- JavaScript
